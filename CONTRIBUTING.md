## Contributing

This repository is my personal clone of the
[AcademicPages](https://github.com/academicpages/academicpages.github.io)
template. If you'd like to contribute to the template itself, please do so
directly on the upstream repository — bug reports, feature requests, and
questions are all welcome there.

- 🐛 [Submit a bug report or feature request](https://github.com/academicpages/academicpages.github.io/issues/new/choose)
- 💬 [Start a discussion](https://github.com/academicpages/academicpages.github.io/discussions)
